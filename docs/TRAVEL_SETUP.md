# 出行准备与密钥配置

## 更新
1. Xcode Run 更新手机 App。
2. Mac 停止旧服务后运行 `server/start.command`。首次输入 OpenAI Key 时，输入 y 可保存到登录钥匙串；以后自动读取。
3. `server/configure.command` 可选择 OpenAI / 高德，保存或删除密钥。运行中的服务需重启才能应用更改。手机和 Git 仓库不保存 Key。

## 高德接入
需要自行申请高德开放平台 **Web 服务 API** Key，并核对自己的地点搜索、公交路线服务权限、配额与费用。不要将 Key 发到聊天里。
- 地点搜索：https://developer.amap.com/api/webservice/guide/api/search/
- 路径规划：https://developer.amap.com/api/webservice/guide/api/direction

双击 configure.command，选择 2（高德），隐藏输入 Key 并选择保存。重启服务。

## 使用
出行准备 → 输入城市与起终点名称 → 分别从搜索候选中选择准确地点 → 查询公交/驾车/步行 → 选择活动开始时间、提前到达时间和活动时长 → 载入日程草稿 → 在日程助手修改活动名称并提交。

查询使用高德真实地点与路线接口，起终点及查询会发送给高德。支持驾车、步行以及公交/地铁方案；未支持的铁路/出租车组合不展示。当前路线耗时加上用户设定的提前到达缓冲，用于计算建议出发时间；不保证未来日期班次。草稿包含查询时间和路线摘要。默认展示路线摘要，完整指引折叠；主动点击高德链接才跳转，并按起终点重新查询。当前不自动抓取定位，不读取高德 App。

首版查询需留在前台，尚未纳入日历后台任务执行队列。地图 Key 未配置不影响日程助手。开发期间曾使用真实 Key 查询机场路线，用户也已反馈搜索、路线及日程备注通过；其他账户权限和每次返回结果仍需验证。

## 板块
- 日程助手：输入任务、保留草稿、提交。
- 出行准备：地点确认、方案查询、生成草稿。
- 任务记录：日程任务历史、撤销/重试、执行回执。
- 设置：Mac 地址、参与冲突检查的日历、测试入口、密钥配置说明。

## 演示部署
Mac 上的 Python 网关就是本地服务端（尚未部署到云端）。演示需保持 Mac 开机、服务终端运行，iPhone 与 Mac 在可互通的可信局域网；日常运行不依赖 USB 数据线。地图及模型调用需要 Mac 能访问对应服务。换网络后核对手机配置的 Mac 地址。签名安装与更新另由 Xcode 完成。

任务输入：冷启动默认空白，可恢复上次非空输入；切后台再回来保留当前内容。一键清空只清空编辑区，不删除任务和日历，仍可恢复最近非空输入。系统回收进程后按冷启动处理。

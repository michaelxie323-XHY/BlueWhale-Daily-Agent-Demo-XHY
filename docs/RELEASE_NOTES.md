## 交付物
`WhaleCompanion-v0.2.0-source.zip` 为源码交付包，包含 Xcode 工程、Swift 源码、Python 服务、测试和 Markdown 手册。包含 SHA256SUMS.txt 用于检查包内文件，外部 .sha256 文件用于校验 ZIP。

不包含 .git 历史、API Key、手机任务数据、构建目录、个人 Xcode 工作区状态、签名证书或安装包。接收者需要自己的签名团队和服务商 Key。项目内 Team 标识仅为构建设置，安装前必须选择自己的 Team。

## 验证与边界
封装时复跑 Python 13 项测试、Swift 排程断言及 iphoneos 无签名编译；详见 VALIDATION.md 的证据区分。仍然是本地网关演示原型：地图查询需前台，自然语言改期仅作常见表达拦截，系统可结束后台任务，网关不宜暴露公网。

此次不上传 GitHub、不发布 App Store、不生成可通用安装的 IPA。录制前按 DEMO_DEFENSE.md 完整演练，并确认更新后的 App 可从桌面独立启动。

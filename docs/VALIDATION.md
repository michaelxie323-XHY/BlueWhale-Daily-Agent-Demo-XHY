# 验收记录与已知限制

截至 2026-10-02。以下区分证据来源，不将口头反馈等同于自动化录屏或大规模稳定性测量。

## 自动化与构建
- Python unittest：模型响应解析/字段校验，以及地图空字段、夜班参数、模式选择、时长解析等（目前13项）。地图测试主要使用模拟响应，不验证每次真实 API 结果。
- Swift 可执行断言：重叠、边界、无空位、固定活动优先、跨日窗口、路程占用、提醒范围、节假日默认策略、撤销归属标记、改期候选空档、修改表达拦截。
- Xcode iphoneos unsigned build：验证编译，不验证签名安装或后台行为。

## 用户反馈已通过
- 日程后台完成时，备忘录/手机搜索持续打字与刷视频正常。
- 多天、指定时间、备注、链接、提醒及独立日历。
- 地点搜索、公交/驾车/步行查询、路线摘要、高德链接、路线备注写入。
- 撤销入口不误跳链接；核对已移动或已删除事件。
- 改期测试：活动冲突、路程冲突、边界相接、跨天跨月。
- 改期确认前新增冲突，以及手动修改备注后的保护。
- 草稿恢复、输入清空等体验已有用户反馈。
- 最新界面调整：居中蓝色标题、列表直接选定活动改期、定位并展开原任务已完成编译；用户反馈版本可封装，尚未提供逐项独立验收记录。

以上未记录每次独立测试的调试器附加状态、精确延迟或失败率，不能宣称“100%可靠”。建议录制前记录3次独立启动测试：日期、输入、前后台切换时间、完成时间、实际结果、是否连接调试器。

## 已知限制
- 地图查询需前台；路线是查询时估计，不是未来日期交通保证；高德 App 与 Web API 可能不同。
- 日程助手显示的是鲸伴本地已保存记录，系统日历手动变更不会自动同步列表。
- 自然语言新建最多20项、整体跨度31天；有界重复展开，不支持无限重复；固定冲突整批拒绝，灵活排程是贪心策略。
- 路程是独立事件，最多240分钟，不是苹果原生“行程时间”字段。
- 自然语言修改仅常见表达拦截；不支持完整语义改期、任意第三方日程修改。
- 改期保留原路线耗时，不自动重新查询；活动与出发预留的旧关联依赖标题和相邻时间。
- 一键重试仅当天明确未写入且无事件记录的失败任务；结果待核对需人工核实。
- App 退出/系统回收不保证任务继续完成；数据提交与本地日志有崩溃窗口，预检查不提供外部并发锁。
- 无后台常驻、无自动邮箱连接、无系统备忘录写入、无定位追踪、无服务器用户账户体系。
- 测试/演示须使用真实可用 API Key，其他评审者应配置自己的 Key；免费账户签名和安装有效性受 Apple 账户规则影响。
